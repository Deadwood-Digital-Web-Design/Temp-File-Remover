TEMP REMOVER   (Deadwood Digital)
============================================================

WHAT IT DOES
Clears temp files, crash dumps, Windows Update leftovers and the Recycle Bin.

HOW TO USE IT
1. Double-click '!START HERE - Temp Remover.bat'. Close your other programs first.
2. The window lists what it found. Untick anything you want to keep.
3. Click 'Clear checked' and confirm. The freed space is shown when it finishes.

IS IT SAFE?
It can only touch places on a built-in safe list. It shows a preview and asks before it deletes.
Files in use are skipped. A log of what was deleted is saved in the logs folder.

Tip: run the System Checker first to see how much each remover can win.

NEEDS
Windows 10 or 11 and Python 3.10 or newer. If the PC has no Python, the START HERE file
uses the portable Python on this drive (D:\Python, see the Setup folder).
